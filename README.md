Solmar Bay is an original open-world crime game in the spirit of GTA 6, rebuilt bigger: drive and walk a sun-soaked coastal city, steal cars, a motorcycle and a boat, outrun the Bay Police through a 5-star wanted system with roadblocks and a police helicopter, and run ten story missions for Mama Rosa — with traffic, pedestrians, three weapons, taxi fares, street races, hidden packages, three radio stations, a day/night cycle, a minimap HUD, synthesised sound and a save.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
