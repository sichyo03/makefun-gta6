Solmar Bay is an original open-world crime game in the spirit of GTA 6: drive and walk a sun-soaked coastal city, steal cars, outrun the Bay Police through a 5-star wanted system, and run four story missions for Mama Rosa — with traffic, pedestrians, combat, a minimap HUD, synthesised sound and a save.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
